Bien démarrer

Les premières étapes avec Llink

Se connecter

Connecte-toi avec ton compte Google ou, si ton compte est lié à Think, avec tes identifiants Think. Garde tes identifiants confidentiels.

Choisir un mode

Utilise Chat pour poser tes questions, Traduction pour travailler sur un texte, Work pour créer des livrables et Live pour échanger à la voix ou en vidéo.

Garder le contrôle

Vérifie les réponses importantes. Dans Work, ouvre les fichiers générés et contrôle les résultats avant de les partager.

Chat & Traduction

Discuter et travailler avec du contenu

Comment envoyer un message ?

Écris dans la zone de saisie puis utilise le bouton Envoyer. Tu peux aussi joindre un fichier ou une photo avec le bouton de pièce jointe.

Comment traduire un texte ?

Ouvre le mode Traduction, choisis la langue source et la langue cible, puis envoie le texte ou le document à traduire.

Pourquoi une réponse peut-elle être interrompue ?

Une coupure réseau, une limite de service ou une fermeture de l’application peut interrompre une génération. Reconnecte-toi et reprends la demande. Ne suppose pas qu’un fichier a été enregistré si Work ne le confirme pas.

Work

Un espace de travail pour créer et modifier des fichiers

Créer

Demande à Work de rédiger un document, construire un tableau, préparer une présentation, écrire du code ou organiser un projet.

Importer

Ajoute des documents et des images en pièces jointes. Work peut analyser le contenu et s’appuyer sur le fichier ouvert dans l’éditeur.

Vérifier et exporter

Consulte la démarche, les résultats des outils et les fichiers livrés. Ouvre un fichier dans l’éditeur, puis enregistre ou exporte-le.

Où retrouver mes projets et conversations ?

Utilise les commandes de gestion des conversations et des projets dans Work. Les fichiers locaux restent dans l’espace de travail de l’appareil ; la synchronisation cloud dépend de ta connexion et de ton compte.

Live

Conversation vocale et vidéo

Comment démarrer un appel ?

Ouvre Live, autorise le microphone ou la caméra lorsque le système le demande, puis commence à parler. Tu peux aussi écrire dans la messagerie de l’appel.

Pourquoi la caméra ou le microphone ne fonctionne-t-il pas ?

Vérifie les autorisations Android ou Windows, ferme les autres applications qui utilisent le périphérique et réessaie. Live nécessite une connexion Internet.

Portefeuille et crédits

Le système de paiement de Llink

Pas d’abonnement récurrent. Llink utilise un portefeuille de crédits. La référence commerciale est de 1 crédit = 0,01 USD.

Crédits gratuits

Un quota gratuit quotidien est renouvelé automatiquement. Le nombre exact est affiché dans ton portefeuille.

Crédits Online

Achète le nombre de crédits souhaité. Think calcule le montant en CDF et CinetPay traite le paiement Mobile Money. Les crédits sont ajoutés après confirmation du paiement.

Suivi des coûts

La consommation dépend du modèle, des tokens utilisés et des opérations réalisées. Une génération d’image peut coûter plus qu’un court message.

Pourquoi mes crédits ne sont-ils pas ajoutés immédiatement ?

Le paiement doit d’abord être confirmé par CinetPay via Think. Actualise le statut depuis le portefeuille après le retour du paiement. Un paiement en attente ne crédite pas le solde.

Les crédits Llink sont-ils ajoutés au portefeuille monétaire Think ?

Non. Les crédits Llink sont conservés dans un portefeuille Llink distinct. Ils ne constituent pas un dépôt d’argent dans Think.

Mode Offline

Utilisation locale sur les applications compilées

À savoir : le moteur local est réservé aux applications Android et Windows compilées, après connexion au compte Google. Il n’est pas chargé dans la version Web.

Le mode local utilise un petit modèle embarqué pour les échanges hors connexion. Certaines fonctions avancées, notamment Live et les outils cloud de Work, nécessitent Internet.

Le portefeuille Offline et les achats de crédits Offline restent désactivés tant que les autorisations sécurisées par appareil et la synchronisation anti-double-dépense ne sont pas terminées.

Génération d’images

Créer et retoucher des illustrations dans Work

Comment créer une image ?

Dans Work, utilise le bouton « Générer une image » ou demande explicitement une illustration. Décris le sujet, le style, le cadrage et le format souhaités.

Combien coûte une image ?

Les estimations actuelles sont de 7 crédits pour une image standard 1K et 11 crédits pour une image HD 2K. Le coût peut évoluer avec les tarifs du fournisseur.

Pourquoi l’image n’apparaît-elle pas dans mes fichiers ?

Work doit recevoir le PNG, le vérifier puis le remettre dans les artefacts. Si la vérification échoue, le fichier n’est pas présenté comme un livrable validé.

Dépannage

Résoudre les problèmes courants

Llink ne se connecte pas

Vérifie Internet, l’heure de l’appareil et les autorisations réseau. Si tu utilises Think, vérifie que ton compte est actif et lié à Llink.

Un outil n’est pas disponible

Certains outils dépendent des clés et services configurés sur le serveur. Actualise l’application. Si l’outil reste absent, signale le problème avec le nom de l’outil et le message d’erreur.
